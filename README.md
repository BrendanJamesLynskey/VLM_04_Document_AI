# VLM 04 — Document AI: Donut, ColPali & Layout-Aware Models

A deep-technical presentation covering document AI from OCR pipelines to end-to-end vision models: Donut OCR-free understanding, ColPali vision-based PDF retrieval with MaxSim scoring, LayoutLM and UDOP layout-aware architectures, modern VLMs on DocVQA, chart-to-text with DePlot and Matcha, and four production pipeline patterns for PDF processing at scale.
